# 官方入门摘要（docs.x.ai）

> 据官方 Get started / Create and manage Bots / Overview 整理，便于手机对照。细节以 https://docs.x.ai/grok-bot/ 为准。

## Grok Bot 是什么

- **Bot** = 持久、有名字的 AI 队友（不是一次性聊天会话）
- 在持久云电脑上使用浏览器、文件系统、终端，像人一样登录工具
- 多个 Bot 可互发消息、群聊交接；只在需要你批准时回来
- 可「跟学」一次工作流，存成 Skill / Routine，按计划或事件再跑

## 和 Grok 聊天的区别

| | Grok | Grok Bot |
|---|---|---|
| 形态 | 对话助手 | 一支可派活的团队 |
| 工作场所 | 对话框 | 云端电脑 + 真实应用 |
| 关掉手机 | 对话停 | 可继续跑 Routine |

## 开始之前

常见资格（随政策变化，以登录后页面为准）：SuperGrok Plus / Heavy、Cursor Pro+ / Ultra、Cursor Teams 等；用 **Cursor 账号** 登录。  
需要允许云端数据存储（Legacy Privacy Mode 需先调整）。

## 安装与登录

1. 打开 https://x.ai/bot 下载 macOS / Windows / Linux 桌面端（亦有 iOS；Android 以官方 FAQ 为准）
2. Get started → 浏览器完成 Cursor 登录 → 回到 App
3. 等待云电脑开通；首次会问你常用工具（只影响推荐，不会自动授权）

## 创建第一个 Bot

1. New → Create new agent（或选推荐队友）
2. Edit Profile：短名字 + 一个主职责 + 描述（常驻规则放这里）
3. 对话里下「今天的具体任务」

描述示例：

> Investigate product-performance questions using our observability tools.  
> Preserve links and screenshots, separate evidence from hypotheses.  
> Never change production settings.

## 怎样写第一个好任务

尽量包含五要素：

1. **结果**：要完成什么  
2. **来源**：哪些 App / 文件 / 网页  
3. **约束**：禁止做什么、何时必须请示  
4. **交付物**：表格 / 草稿 / 报告文件  
5. **停点**：何时停下来等你审  

五分钟练习（无需接邮箱）：

> 用五点总结这份文档；另列日期、决策、未决问题；每条注明页码或章节。不要改源文件。

## 登录工具时

Bot 需要密码 / Passkey / 验证码时：打开 **Agent Computer** → 接管 → 你自己输入 → 交还控制权。  
会话会留在共享云电脑上。支持的服务也可在 Settings → Plugins 一键授权。

## 管理建议（官方口径）

- 有稳定职责再拆新 Bot；别一上来建十个  
- 需要看见交接时，用群聊  
- 外发、改权限、花钱等放在审批边界后  
- 共享电脑 = 共享登录与文件；**Bot 不是安全隔离边界**

## 下一步

任务稳定后，让 Bot 保存为 Skill，再考虑 Routine（日程 / 事件触发）。
